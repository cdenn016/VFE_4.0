## Established constructions

A physically marked square frame defines a local flat connection by declaring that frame parallel. A presentation matrix alone does not define a reference-independent connection if one silently resets the reference connection to zero after every context-dependent reference change. The note makes this distinction using the live manuscript's two transformation laws. It also records how an affine combination of already defined flat connections can be curved; that possibility was present in the prior collective-curvature investigation and is not presented as a new discovery.

For a full-row-rank matrix X of law-derived vectors and link-transformed messages in a fixed labeled message space, the normalized cross-map is C(c',c) = X(c') X(c)^T [X(c) X(c)^T]^{-1}. Its value at zero displacement is I. Its derivative selects a = -dX X^T(XX^T)^{-1}, with the full affine reference law. Reciprocal normalization preserves the first jet; ordered products converge to the derived connection's parallel transport along a declared path. The note proves the curvature formula and shows that the fixed-message-metric rule preserves an induced positive fiber metric, so it does not realize arbitrary GL curvature. A constrained least-squares version respects a smaller structure group and can combine both sectors through one Lie-algebra variable.

The second construction aligns a smooth tuple of laws, interfaces, reciprocal links and backtrack factors in a declared invariant metric. An injective infinitesimal action gives a unique local identity branch and its locked-inertia normal equation. A three-agent SO(3) star provides a curved example using reciprocal links alone: the links rotate about two contextually varying nonparallel axes, all backtracks equal I, and the derived base curvature is nonzero. The graph need not contain a nontrivial reciprocal cycle for contextual curvature to appear. The explicit formula is in Section 8.1 of the note.

An invisible-subgroup obstruction identifies a real limit: conjugation-only GL link data cannot determine a scalar connection component, even with all contextual derivatives supplied. Under a gauge change in that invisible subgroup, the input fields stay unchanged while a full connection must acquire an inhomogeneous term. Laws or interface data can resolve the ambiguity only if their action actually sees that subgroup. The SO(3) example has zero common infinitesimal stabilizer and therefore does not encounter this obstruction.

The original directed pairs are retained as reciprocal and backtrack factors, or directly as raw links. A scalar example proves that changing only the backtrack factor can change the selected transport. The new cross-context reconstruction defect is distinguished from an agent backtrack at one context. The connection is not claimed to retain the entire original link state injectively.

## Assumptions and open obligation

Both constructions need smooth contextual data, a declared base, a regular identifiable region, and a specified comparison rule. The rectangular construction additionally uses persistent message labels or a declared message-bundle connection. Such labels can be supplied by the fixed agent census or receiving-interface columns. A finite matrix at one context supplies no contextual derivative. Full rank, identifiability, and a local minimizing branch are not consequences of normalization or gauge covariance alone.

The minimal remaining modeling obligation is to choose which currently retained laws, interfaces and links define the operative comparison, including its metric or normalized probe experiment, and show that the intended dynamics supplies and preserves the required regularity. The new selector generally differs from Item 4's law-only Fisher selector. Inserting it into a contextual energy requires a new full derivative and dynamics analysis. No new formation, parent inheritance, graph-refinement, global regularity, or derived-base claim follows. The separate reports include possible extensions, including context-dependent message weights and an optional normalized link-probe experiment; those are not silently substituted into the principal note.
