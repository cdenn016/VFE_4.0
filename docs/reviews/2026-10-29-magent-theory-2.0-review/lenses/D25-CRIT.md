### D25-CRIT-01: The subcritical type is specific to the published data; one-parameter changes of the references make the pitchfork supercritical
**Category:** weakness
**Severity:** medium
**Location:** chapters/18_link_dynamics.tex:533-552 (it2:critical-pitchfork, "this is a subcritical pitchfork; it creates no locally stable asymmetric branch"), :517, :623, :629 (it2:open-reciprocal); companion/c18_link_dynamics.tex:394, :412; README.md:22; AUTHORING.md:93; chapters/06_outlook.tex:4; future_TODO.md:64
**Evidence:** The theorem is correct for the stated data, and I reproduced c = -657534393590529472/6223404588394626861 exactly (d25_pitchfork_exact.py). Its sign is a near-cancellation: in it2:critical-quartic, A_xxxx[p^4] = 0.361688, 4 Delta_xxx[p^3] = -0.977260, -3 k^T H^{-1} k = -10.357161 and 32 T_c = +10.338802 sum to -0.633931 = 6c; the two dominant terms differ by 0.18 percent. A sensitivity scan (d25_sensitivity.py, float64) changes one datum at a time with the others as published; it locates the symmetric state by Newton, takes T_c = g^T H^{-1} g/4, and estimates c from Phi_s(s, T_c)/s^3 on the continued stationary curve by Richardson extrapolation (the control reproduces the published c to 2e-8 with steps 0.005 and 0.01, d25_sensitivity_confirm.py). It finds c = +0.02294 (T_c = 0.31909) at dictionary reference precision A_omega = 1 instead of 3/4; c = +0.04494 (T_c = 0.30237) at receiver precision P_0 = 1.5 instead of 1; c = +0.02719 at source precision 3/4 instead of 5/4; and c = +0.00865 at source reference mean magnitude 1.25 instead of 23/15. In the flipped cases T_b(s) - T_c < 0 for small s (for A_omega = 1: -1.44e-7, -5.78e-7, -1.71e-5 at s = 0.005, 0.01, 0.05), so the small asymmetric equilibria lie below T_c; since Phi_ss = -h'(s) T_b'(s) > 0 there and the matter block stays positive definite, they are local minima, and a locally stable selected branch is born continuously as T decreases. Moving the data the other way (A_omega <= 3/4, P_0 <= 1, source precision >= 5/4, source mean magnitude >= 23/15) keeps c < 0. A surface c = 0 (a tricritical surface in Landau language) therefore separates the two types close to the published point, for example between A_omega = 3/4 and 1. The manuscript, companion, README, AUTHORING and outlook present "subcritical pitchfork, no locally stable asymmetric branch" as the example's lesson without saying that the type depends on the reference data. The theorem's data are explicit, so this is not an inflation of the theorem, but the example is much weaker evidence about coupled source selection than its summaries suggest.
**Fix:** After it2:critical-pitchfork add a remark that c depends on the reference data, that it2:critical-quartic is the general formula for any symmetric two-candidate configuration, and that, for example, A_omega = 1 gives c > 0 and a supercritical pitchfork with locally stable asymmetric branches below T_c. Qualify the summaries as "for these data". A clean exact companion example can be built by retuning the source reference means so that the symmetric state stays rational at A_omega = 1.
**Falsifies:** An exact or interval-validated computation at A_omega = 1 (other data as published) giving c <= 0, or a demonstration that the scan's symmetric state is not a fixed-row matter minimum.

### D25-CRIT-02: D versus D+4 compares two reduced kinetic metrics; Gibbs reduction with the pullback metric reproduces full relaxation's leading center dynamics exactly
**Category:** improvement
**Severity:** medium
**Location:** chapters/18_link_dynamics.tex:361, :537-540 (it2:critical-normal-form), :601-613, :623 ("a leading time scale about 6.34 times longer"); companion/c18_link_dynamics.tex:246, :403-410 ("Adding the Gibbs row's pullback metric to the reduced flow would change the specified dynamics")
**Evidence:** I computed the center-manifold coefficients of u' = a1 (T - T_c) u + a3 u^3 directly from the actual vector fields by the standard projection formula, a1 = l^T (dJ/dT) q and a3 = l^T D^3F[q,q,q]/6 + l^T D^2F[q,h2]/2 with J h2 = -D^2F[q,q] and l^T h2 = 0. The formula differentiates F = -G^{-1} grad V itself, so every mobility derivative is included (d25_cm_flow.py, d25_cm_pullback.py, exact rationals). Full relaxation: a1 = -25593481/30390845 = -4/(D+4) and a3 = 164383598397632368/7389949191287808945 = -c/(D+4). Matter-metric Gibbs reduction: a1 = -25593481/4797364 = -4/D and a3 = 41095899599408092/291636150723295521 = -c/D. Gibbs reduction with the pullback metric g_pb = M^{-1} + grad b* grad b*^T/(b*(1-b*)): a1 = -4/(D+4) and a3 = -c/(D+4), identical to full relaxation, with squared pullback length |p|^2_pb = 121563380/25593481 = D + 4. The reason is general. For a gradient flow y' = -G(y)^{-1} grad V at a simple Z_2-symmetric zero mode with kernel vector q, the derivatives of G multiply quantities that vanish at orders (T - T_c) u and u^3 (this is the manuscript's "variation of M contributes only at higher orders", line 606), so u' = -(4 delta u + c u^3)/|q|^2_G plus higher order, where 4 and c are Lyapunov-Schmidt coefficients of V that coincide for the full potential, the Gibbs potential and the stationary potential Phi. The kernel vector of the full Hessian is (p, D beta*[p]), and its full Fisher length is |p|^2_m + |D beta*[p]|^2_row = |p|^2_pb. The factor (D+4)/D = 6.3349 is therefore the ratio of the pullback length to the matter length of p. It measures the row's kinetic cost, which matter-metric Gibbs reduction omits; it is not an extra slowness that row relaxation adds to a correctly reduced flow. The companion's sentence at c18:410 is true but leaves out that the change produced by the pullback metric is exactly a change to the full-relaxation leading dynamics.
**Fix:** State the lemma; the manuscript's own computation w = -B f with B = H^{-1} M_*^{-1} p generalizes verbatim to any positive metric with B = H^{-1} G_* q. Add that pullback-metric Gibbs reduction and full relaxation have the same leading center coefficients, and rephrase line 623 and c18:410 accordingly, keeping the caveat that transverse spectra and higher-order paths differ.
**Falsifies:** An independent computation of the pullback-metric center coefficients that differs from -4/(D+4) and -c/(D+4).

### D25-CRIT-03: it2:coupled-global stops short of convergence to a single stationary point, which the Łojasiewicz argument of prop:dyn-global-flow gives at no cost
**Category:** improvement
**Severity:** medium
**Location:** chapters/18_link_dynamics.tex:390-415 (it2:coupled-global; line 415: "it neither proves uniqueness of the stationary point nor asserts convergence to one particular point"); companion/c18_link_dynamics.tex:275; compare chapters/03_dynamics.tex:180-184 (prop:dyn-global-flow)
**Evidence:** The theorem's own proof establishes that each trajectory has compact closure in the open product of mean spaces, positive-definite cones and simplex interiors. Both potentials are real-analytic there (Gaussian KLs, log det, trace terms rational in the covariances, beta log beta, log-sum-exp), and the product Fisher metric is analytic and, on the compact closure, uniformly equivalent to the Euclidean metric of the affine coordinates. Near an omega-limit point y_bar the Łojasiewicz inequality |V - V(y_bar)|^{1-theta} <= C |grad V| holds, and along the flow d/dt (V - V(y_bar))^theta <= -(theta lambda_min/(C lambda_max)) |y'|, so the path has finite length and converges to y_bar. Chapter 3 uses exactly this argument, with the same citations (Lojasiewicz1963, AbsilMahonyAndrews2005), for finite tables. This is the Gaussian counterpart of 2026-10-22 L03-DYN-05, which was resolved for finite tables but not carried into the new Gaussian theorem.
**Fix:** Add "and every trajectory converges to a single stationary point" to it2:coupled-global with the three-line argument, replace the sentence at line 415 by "it does not prove uniqueness of the stationary point", and adjust c18:275.
**Falsifies:** A bounded interior trajectory of either Gaussian flow whose omega-limit set is a nontrivial continuum; Łojasiewicz's theorem excludes this for analytic gradient-like flows.

### D25-CRIT-04: The distant branch reduces exactly to a scalar continuation; numerically it folds just above T_c, giving bistability and a strongly selected destination below T_c
**Category:** extension
**Severity:** medium
**Location:** chapters/18_link_dynamics.tex:623 ("Distant stable equilibria, folds, and the destinations ... require separate arguments"), :628-629 (it2:open-reciprocal); companion/c18_link_dynamics.tex:412
**Evidence:** Exact reduction: the stationary matter curve X(s), defined by G_x(X(s), s) = 0, does not depend on T, and Phi_s(s, T) = Delta(X(s)) + T h'(s). Hence (X(s), s) is a full stationary point exactly at the temperature T_b(s) = -Delta(X(s))/h'(s), and Phi_ss(s, T_b(s)) = -h'(s) T_b'(s). Wherever K(s) = G_xx(X(s), s) is positive definite, the full Hessian has ten positive directions plus the sign of Phi_ss, and the reduced Hessian follows by the Schur complement; the branch is a saddle where T_b increases and a strict local minimum, locally exponentially stable for both flows, where T_b decreases. Numerics (d25_branches_numeric.py, Newton continuation in 5000 steps on s in (0, 0.4999), float64): K(s) stays positive definite (minimum eigenvalue 0.281) and every variance stays above 0.800; (T_b(s) - T_c)/(-c s^2/4) = 0.99998 at s = 0.001; T_b has a single maximum T_f = 0.3234850 at s_f = 0.1690 (T_f - T_c = 3.97e-4), then decreases strictly to 0.1103 at s = 0.4999 and crosses T_c at s = 0.2331. Direct Jacobians confirm real spectra, exactly one unstable eigenvalue on the small-s saddles (full 4.434e-6 against the predicted 8 delta/(D+4) = 4.442e-6 at s = 0.01; reduced 2.809e-5 against 8 delta/D = 2.814e-5), and no unstable eigenvalue on the post-fold branch (at T = 0.30003, s = 0.4150 the largest real parts are -0.0645 for the full flow and -0.319 for the reduced flow). Trajectories (d25_trajectories.py, BDF with analytic Jacobian): at T = 0.30 both flows started at x_* + 1e-3 p converge to s = 0.415101 (b = 0.9151) with residual speed below 1e-15; at T = 0.3234, inside (T_c, T_f), a start at x_* + 1e-2 p returns toward x_* while a start at the T = 0.30 endpoint settles at s = 0.201946 for both flows. At the selected state the dictionary stationarity equation it2:coupled-stationarity holds to 1e-16 (V_1 = 0.83261 on the attended edge, V_2 = 1.25705 on the other). The exact sixth-order coefficient (d25_sixth_order.py) is Phi_ssssss(0, T_c) = 4153604262368054569136406470570309838848/24245963967698369479677901569046003773 = 171.311 > 0, so T_b(s) = T_c - (c/4) s^2 + e4 s^4 + O(s^6) with e4 = -0.39212. The leading-order fold estimate is s_f = 0.184 and T_f - T_c = c^2/(64|e4|) = 4.45e-4, consistent with the continuation. In Landau language, Phi(s, T) - Phi(0, T) = 2(T - T_c) s^2 + (c/4) s^4 + Phi_6 s^6/720 has a negative quartic and a positive sextic coefficient, the first-order case, with metastability window (T_c, T_f). These are exact jets plus numerical observations on one example; the fold and the stable branch are not proved.
**Fix:** State the exact reduction T_b(s) with its stability criterion as a proposition, valid wherever the continued curve exists with K positive definite. Prove the fold and the stable branch by validated continuation (interval Newton or Krawczyk enclosures of X(s), T_b and T_b' for s in [0, 0.49]); difficulty low to moderate. A destination theorem below T_c needs, in addition, the complete equilibrium set and the single-limit convergence of D25-CRIT-03; that is harder.
**Falsifies:** A validated computation showing that T_b has no interior maximum on (0, 0.25), or a trajectory at T = 0.30 from x_* + eps p that converges to an equilibrium other than the selected state.

### D25-CRIT-07: The equivariant center-manifold theorem is dispensable, and instability at T_c has an elementary energy proof
**Category:** improvement
**Severity:** low
**Location:** chapters/18_link_dynamics.tex:589 (\citep[Theorem~1.2]{Ruelle1973Symmetry}), :613, :620; companion/c18_link_dynamics.tex:401
**Evidence:** Equivariance of the center manifold is not needed. If W is any local C^7 center manifold of the suspended system, its image under the reflection is again one, and Taylor jets of center manifolds at the equilibrium are unique, so the jet of the reduced field f is odd through order six; with f(0, delta) = 0 this gives the stated remainder O(delta^2|s| + |delta||s|^3 + |s|^5) by Taylor's theorem. Nonlinear instability at T_c also follows without any center manifold: by it2:critical-quartic, Phi(s, T_c) - Phi(0, T_c) = (c/4) s^4 + O(s^6) < 0, so the points (X(s), s) have lower full energy arbitrarily close to the equilibrium, and E_{T_c}(X(s)) <= Phi(s, T_c) gives the same for the reduced potential; for a gradient flow with positive-definite metric, an isolated equilibrium with arbitrarily close lower-energy points is Lyapunov unstable (the record stationary-reduction.md states this argument; the manuscript does not use it). I could not check the cited Ruelle theorem: the IHES file in the bibliography URL is a password-protected scan, the preprint copy exceeded the fetch limit, and the Exa tools were out of credits. The integration README states that the paper was checked, which is agent-produced.
**Fix:** Either cite a standard parameter-dependent center-manifold theorem whose exact statement a reader can find (for example Carr 1981, chapter 1, or Vanderbauwhede 1989) together with the uniqueness-of-jets remark, or quote the hypotheses of Ruelle's Theorem 1.2. Use the energy argument as the primary proof of instability at T_c; it covers both flows at once.
**Falsifies:** A C^7 vector field with two local center manifolds whose Taylor jets differ at the equilibrium (none exists).

### D25-CRIT-09: Lyapunov-Schmidt recognition of the pitchfork and the Landau reading are not attributed

**Severity:** low
**Location:** chapters/18_link_dynamics.tex:519-623 (it2:ch-critical-mode, it2:critical-pitchfork)

Rev. Lett. 24 (1970) 715). The section cites only Ruelle 1973 for the center manifold. I did not re-read these sources for this report, so the locators should be checked before use.
**Fix:** One attribution sentence at the start of it2:ch-critical-mode.
**Falsifies:** Not applicable.

## Extensions and improvements

A general symmetric two-source proposition would replace the example-specific theorem at little cost. For any receiver with exactly two candidates of equal prior at a configuration fixed by an involution that exchanges them, it2:coupled-hessian at equal costs gives H_T = H - g g^T/(4T) with g the gradient of the cost difference, so T_c = g^T H^{-1} g/4 whenever the fixed-row matter Hessian H is positive definite, and the stationary elimination gives Phi_ssss(0, T_c) = A_xxxx[p^4] + 4 Delta_xxx[p^3] - 3 k^T H^{-1} k + 32 T_c with p = -H^{-1} g, verbatim. Combined with the lemma of D25-CRIT-02 this yields the full normal form u' = -(4 delta u + c u^3)/|q|^2_G for any positive kinetic metric, and the sensitivity scan of D25-CRIT-01 shows that both signs of c occur within the three-agent family. The natural next statement is a description of the tricritical surface c = 0 in the reference data and of its unfolding by the sextic coefficient, which I computed exactly for the published data (D25-CRIT-04); near that surface the fold distance obeys T_f - T_c = c^2/(64|e4|) at leading order, which gives a quantitative hysteresis law. Difficulty: low for the proposition, moderate for a full description of the surface.

For rows with n >= 3 symmetric candidates the same computation gives T_c as the largest generalized eigenvalue of the pencil (Sigma_c, H), where Sigma_c = sum_e beta*_e (c_e - c_bar)(c_e - c_bar)^T is the Gibbs covariance of the cost gradients and T_c = sup_xi xi^T Sigma_c xi/xi^T H xi. With an S_n symmetry the critical eigenspace carries the standard representation, which admits quadratic equivariants for n >= 3, so equivariant bifurcation theory leads one to expect transcritical-type branches that are unstable near onset; this should be checked against the equivariant branching lemma before it is stated. Difficulty: moderate.

The distant branch of the example can be made a theorem by validated numerics. The exact reduction of D25-CRIT-04 reduces the problem to enclosing the ten-dimensional curve X(s) and the scalar T_b(s) = -Delta(X(s))/h'(s) on s in [0, 0.49], together with K(s) positive definite; an interval Newton or Krawczyk continuation with a few thousand steps would certify the fold at T_f, the stable branch down to T of about 0.11 and the bistability window (T_c, T_f). A destination statement below T_c (trajectories leaving the symmetric saddle converge to the selected state) then needs the equilibrium set and the single-limit convergence that D25-CRIT-03 supplies. The selected state is also informative for the program: at T = 0.30 the receiver attends to one source with weight 0.915, the attended dictionary contracts from variance 1 to 0.833 while the other relaxes toward its prior variance 4/3, and the attended source widens (1.029) while the unattended one sharpens (0.867), which is the source-role moment matching of it2:certainty acting with unequal weights.

The kinetic lemma of D25-CRIT-02 also settles which reduced convention to use when a Gibbs-reduced model is meant to approximate full row relaxation near a critical point: the pullback metric reproduces the leading center coefficients exactly, while the matter metric speeds the center dynamics by |p|^2_pb/|p|^2_m. Stating this lets later chapters choose a convention by its approximation property rather than by convenience. Difficulty: low.
