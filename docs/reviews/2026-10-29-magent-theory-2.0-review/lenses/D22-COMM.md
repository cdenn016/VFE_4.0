### D22-COMM-01: Identifying the dictionary presumes the receiver knows the sender’s reference code
**Category:** gap
**Severity:** medium
**Location:** chapters/17_communication_links.tex:133-157 (`it1:grounded-model`, `it1:identifiability`), :205 (reading of `it1:query-dictionary`), :30 (shared-language sentence); frontmatter.tex:19; chapters/01_foundations.tex:185-193 (`def:shared-model`); chapters/17_communication_links.tex:491-492 (`it1:open-codes`).
**Evidence:** The receiver’s model $h\mid\bar y\sim\mathcal N(\bar T\bar\theta^{-1}\bar y,R)$ treats the sender’s reference code $\bar T$ as a known matrix, and parts (i)-(iii) quantify only over dictionaries. Messages depend on the pair $(\bar T,\bar\theta)$ only through the effective code $\hat A=\bar T\bar\theta^{-1}$, and $(\bar T g)(\bar\theta g)^{-1}=\bar T\bar\theta^{-1}$ for every $g\in G$. Script s02 (f) gives a residual of $1.2\times10^{-15}$ for this identity with $\bar Tg\neq\bar T$. If $\bar T$ is not known, the grounded experiment identifies $\hat A$ and nothing about $\bar\theta$ separately. The stabilizer quotient of part (i) answers the question only after $\bar T$ is fixed. The chapter’s only stated source for that knowledge is line 30: “A shared language is part of a shared generative model in the sense of \cref{sec:generative-models}: members of a species use codes related by the frame map of their shared model”. But `def:shared-model` consists of $r_i,G_i,\ell_i$ and the bijections $\phi,\psi$, with no code component. The same line also says “Codes are agent specific”, and `it1:open-codes` poses as open the question of when learned codes become related by the frame map. The abstract states “Grounded messages identify dictionaries modulo code stabilizers” without the hypothesis, and line 205 (“holds exactly the identifiable part of a dictionary”) inherits it as well.
**Fix:** Add to `it1:identifiability` and to the abstract sentence the hypothesis “the receiver knows the sender’s reference code $\bar T$ (for example, a declared species code shared in reference coordinates)”. Add the one-line converse: when $\bar T$ is unknown, only $\hat A$ is identified. Then either give `def:shared-model` a code component or replace “in the sense of \cref{sec:generative-models}” with an explicitly declared language hypothesis.
**Falsifies:** A standing hypothesis in chapters 1, 2 or 17 that makes each sender’s reference code known receiver data, or a definition of a shared generative model that contains the codes. I found neither.

### D22-COMM-02: The data-processing bound on source-row costs needs one common code for the true and candidate message laws
**Category:** gap
**Severity:** medium
**Location:** chapters/17_communication_links.tex:275 (remark after `it1:bandwidth`).
**Evidence:** “The costs are divergences between message laws, which are code-visible divergences: by data processing they are at most the corresponding divergences between full beliefs, with equality exactly when the code is sufficient.” Data processing bounds $\KL(q\mathcal K\Vert q_2\mathcal K)\leq\KL(q\Vert q_2)$ only when one kernel $\mathcal K$ is applied to both laws. The costs $\KL(\nu\Vert\nu_j)$ compare the law of what was heard with candidate $j$’s message law. In the chapter’s own model, codes are agent specific (line 30), and candidate message laws carry their own effective codes $\bar T_k^c\bar\theta_{ik}^{-1}$ (`it1:routed`, line 186). Counterexample (s05 (d)): take $q=q_j=\mathcal N(0,1)$, true code $1$ and candidate code $2$. Then the message-law divergence is $0.3181>0=\KL(q\Vert q_j)$. The same example shows that the equality clause also presupposes a common code. The next sentence (“When a common noiseless injective code is used...”) states the common-code hypothesis only for the equality case.
**Fix:** Write: “When the true source and candidate $j$ emit through one common kernel $\mathcal K$, data processing gives $\KL(q\mathcal K\Vert q_j\mathcal K)\leq\KL(q\Vert q_j)$, with equality exactly when $\mathcal K$ is sufficient for the pair; for different codes no such comparison holds.”
**Falsifies:** A reading of “the corresponding divergences between full beliefs” in which the compared full objects include the codes, for example the joint laws of content and message. Under that reading the full divergence in the counterexample is infinite, and the bound is restored.

### D22-COMM-03: For compact dictionary groups the invisible part is far smaller than the GL count, and a rank-$(K-1)$ code identifies an $SO(K)$ dictionary
**Category:** extension
**Severity:** medium
**Location:** chapters/17_communication_links.tex:152-157 (`it1:identifiability` (iii) and the following paragraph); companion/c17_communication_links.tex:113-117.
**Evidence:** Part (iii) gives $\dim\operatorname{Stab}=K(K-r)$ for $\GL(K,\R)$ only, although line 7 allows any $G\subseteq\GL(V)$, and the program’s curved example in chapter 16 uses $SO(3)$. For orthogonal $g$, the condition $\bar Tg=\bar T$ means $g^T$, and hence $g$, fixes $\operatorname{row}\bar T$ pointwise and preserves $\ker\bar T=(\operatorname{row}\bar T)^\perp$. So $\operatorname{Stab}_{SO(K)}(\bar T)\cong SO(K-r)$, and the identifiable dimension is $K(K-1)/2-(K-r)(K-r-1)/2=r(2K-r-1)/2$. Script s02 (d) finds $\dim\{\delta\in\mathfrak{so}(K):\bar T\delta=0\}=1,0,1,3$ for $(K,r)=(3,1),(3,2),(4,2),(5,2)$, as predicted, against GL counts $K(K-r)=6,3,8,15$. A rank-2 code therefore identifies an $SO(3)$ dictionary completely, while in $\GL(3)$ it leaves three invisible directions. Read together with (iii), the sentence “Messages never test the part of the dictionary that the code discards” carries the GL magnitude.
**Fix:** Add a part (iv): for $G=SO(K)$ (respectively $O(K)$), $\operatorname{Stab}_G(\bar T)$ is the pointwise stabilizer of $\operatorname{row}\bar T$, isomorphic to $SO(K-r)$ (respectively $O(K-r)$), and the identifiable dimension is $r(2K-r-1)/2$. State that $\GL(K)$ is the case of maximal invisibility. Difficulty: low, one paragraph.
**Falsifies:** An element of $\mathfrak{so}(K)$ with $\bar T\delta=0$ outside the $\mathfrak{so}(\ker\bar T)$ block, or a declared restriction of chapter 17 to $G=\GL(K)$. There is no such restriction.

### D22-COMM-05: The dissonance definition calls the covariance-dressed defect a conjugation-invariant defect of the holonomy, which it is not
**Category:** consistency
**Severity:** low
**Location:** chapters/17_communication_links.tex:249 (`it1:dissonance`); chapters/02_interactions.tex:219-230 (`prop:int-loop-defect`).
**Evidence:** “A quantitative label is any conjugation-invariant defect of $H_\gamma$, for example $\Vert H_\gamma-I\Vert_F$ for orthogonal dictionaries; for general dictionaries the covariance-dressed loop defect of \cref{prop:int-loop-defect} supplies an invariant measure.” For $\GL$ dictionaries every continuous function of $H_\gamma$ that is conjugation invariant and zero at $I$ vanishes on unipotent loops; 02_interactions:230 says exactly this. Script s04 (d): conjugating $I+E_{12}$ by $\operatorname{diag}(t,1)$ drives the entries to $I$, with $Q(\cdot;I)=0.5,\ 5\times10^{-5},\ 5\times10^{-9}$ at $t=1,10^{-2},10^{-4}$. The dressed defect $Q(H;\Sigma)$ is invariant only under joint re-expression of $(H,\Sigma)$ (residual $3.9\times10^{-14}$) and is not a function of $H$ alone: $Q(I+E_{12};I)=0.5$ while $Q(I+E_{12};\operatorname{diag}(1,4))=2.0$. The sentence therefore puts its own example for general dictionaries outside the class it defines. Separately, `prop:int-loop-defect` is stated for two-cycles $W=\Theta_{ij}\Theta_{ji}$ and titled “Law-dressed loop defect”, while chapter 17 applies it to every directed closed walk under the name “covariance-dressed”. Its proof extends verbatim.
**Fix:** Replace the sentence by: “For compact $G$ a continuous conjugation-invariant defect such as $\Vert H_\gamma-I\Vert_F$ suffices. For $G=\GL(K)$ no continuous conjugation-invariant function of $H_\gamma$ alone vanishes only at $I$; use $Q(H_\gamma;\Sigma_{i_0})$, which is invariant under joint re-expression of the loop and the base covariance.” State `prop:int-loop-defect` for an arbitrary loop based at $i$, under one name.
**Falsifies:** A declared restriction of `it1:dissonance` to compact $G$, or a dressed defect that is a function of the conjugacy class of $H_\gamma$ alone. The unipotent example excludes the latter.

### D22-COMM-07: The meaning lost through a code depends on the stabilizer component of the dictionary, which no message tests

### D22-COMM-10: Citation and attribution details in the location-noise, routing, Kalman and frustration passages
**Category:** citation
**Severity:** low
**Location:** chapters/17_communication_links.tex:165 (`it1:location`), :194 (`it1:routed` proof), :98 (`it1:kalman` proof), :246.
**Evidence:** (a) Line 165 asserts that Gaussian noise has the least Fisher information at a given covariance “by the Cramér–Rao inequality for location families”, with no source and without stating that $R=\operatorname{Cov}(\varepsilon)$ is finite for a general $\nu$. The matrix inequality $J_f\succeq\operatorname{Cov}(\varepsilon)^{-1}$ follows from $\E[\nabla\log f(\varepsilon)\varepsilon^T]=-I$ (integration by parts, needing decay of $f(x)x$) and positivity of the joint covariance of $(\nabla\log f(\varepsilon),\varepsilon)$. Scalar Student-$t$ values ($J=(\nu+1)/(\nu+3)\geq(\nu-2)/\nu$ for $\nu=3,5,10,30$, s02 (e)) are consistent with it. (b) Line 194 attributes “the missing-information principle” to Louis 1982. The principle is due to Orchard and Woodbury (1972, Proc. Sixth Berkeley Symp., vol. 1; page range not verified here), and Louis gives the observed-information formula under EM. The inequality the proof uses is the law of total variance for the complete-data score, $I_{\mathrm{comp}}-I_{\mathrm{obs}}=\E[\operatorname{Var}(S_{\mathrm{comp}}\mid\text{observed})]\succeq0$, which needs no citation beyond that. (c) Line 246 attributes the study of “its least eigenvalue as a measure of frustration” to Singer and Wu 2012 as well as Bandeira, Singer and Spielman 2013. The frustration constant and its Cheeger inequality are Bandeira–Singer–Spielman’s; Singer–Wu introduce the connection Laplacian for vector diffusion maps. (d) Line 98 cites Kalman 1960 for Gaussian conditioning, which predates the filter. A multivariate-analysis text is the primary source (for example Anderson, *An Introduction to Multivariate Statistical Analysis*, section 2.5; locator from memory, not opened).
**Fix:** Cite a source for the location-family Cramér–Rao inequality and state the finite-covariance hypothesis; attribute the missing-information principle to Orchard and Woodbury or state the total-variance inequality directly; restrict the frustration attribution to Bandeira–Singer–Spielman; cite a conditioning reference beside Kalman.
**Falsifies:** Source text showing that Singer–Wu 2012 analyze the least eigenvalue as frustration, or that Louis 1982 introduced the missing-information principle. I did not open either paper in this run.

## Answers to the focus questions

1. Lossy code versus invertible dictionary. Chapter 17 does not define the future_TODO object $M_{ij}=U_iO_iT_jU_j^{-1}$. Its reference-coordinate instance is the noiseless composite $G\bar T_j$ (equivalently the projector $P=G\hat A$) in the mean update `it1:mean-update`, which has rank at most $r$. The identity $e^{OT}=I+O\varphi_1(TO)T$, $\det e^{OT}=e^{\Tr OT}>0$ and $e^P=I+(e-1)P$ hold (checked-table rows `it1:exponential`). The Higham 2008 locator, section 1.8 “f(AB) and f(BA)”, is correct. The single-exponential caveat is correct: $\operatorname{diag}(-1,-2)\in\GL^+(2,\R)$ has no real logarithm, since a logarithm of a matrix with distinct eigenvalues commutes with it, is therefore diagonal, and would need $e^{x_1}=-1$. This agrees with the Culver 1966 citation, which I did not open. The closing sentence of the remark is imprecise (D22-COMM-08 (a)).
2. Reception through a code. The general-law loss identity follows from `cor:pythagorean`, and the noisy bound from the chain rule plus data processing over the posterior mixture. Both proofs were reconstructed. All Gaussian decoding and reconstruction formulas hold at machine precision. No defect; see the table. A low-cost improvement: `it1:kalman` does not need full row rank.
3. What messages reveal. Parts (i)-(iii) are correct for the stated model. Tested at $(K,r)=(3,2),(5,2)$: Fisher rank $Kr$, kernel $\{\bar T\delta=0\}$, stabilizer cosets leave the effective code unchanged. A single operating content gives Fisher rank $r$ rather than $Kr$, and the companion example $\delta=E_{22}$, $c=e_1$ behaves as stated. Findings: D22-COMM-01 (known-code hypothesis), D22-COMM-03 (compact groups), D22-COMM-07 (loss not identifiable).
4. Several modalities. `it1:modalities`, `it1:routed`, `it1:query-dictionary` and `it1:stack-compatibility` are correct. The row-relation criterion is necessary and sufficient, and the counterexample and random stacks behave as stated. No defect.
5. Curvature as dissonance. The quarter-turn values, joint invariance and tangent-form claims of `it1:loop-comparisons` hold. The KL tangent form has rank 6 of 9 at zero mean and 8 of 9 at nonzero mean, while the dressed form has rank 9. Findings: D22-COMM-05 (class-function wording, naming), D22-COMM-06 (companion qualifier).
6. Bandwidth and directed consensus. `it1:bandwidth` is correct as repaired after G6, and `it1:consensus` is correct. Findings: D22-COMM-02 (data-processing remark), D22-COMM-04 (frustration hypothesis).
7. Companion c17 lines 1-199. Every worked example was recomputed and is correct. Finding: D22-COMM-06. Notation drift ($A_{ij}$) is noted in D22-COMM-08.

## Extensions and improvements

Finite-alphabet codes through a logit map are the cheapest partial answer to `it1:open-general`. Let a sender emit $h\in\{1,\ldots,m\}$ with $\mathbb P(h=c\mid\bar y)=\operatorname{softmax}(W\bar\theta^{-1}\bar y)_c$ for a known $W\in\R^{m\times K}$. Softmax is injective modulo the all-ones direction, so two dictionaries give the same conditional laws for every referent exactly when $\bar\theta'^{-1}\bar\theta''\in\operatorname{Stab}(CW)$, with $C=I_m-\mathbf 1\mathbf 1^T/m$. The Fisher form is $F(\delta,\delta)=\E_\rho[(W\delta\bar\theta^{-1}\bar y)^T(\operatorname{diag}p-pp^T)(W\delta\bar\theta^{-1}\bar y)]$, and its kernel is $\{\delta:CW\delta=0\}$, because $\operatorname{diag}p-pp^T$ has kernel $\operatorname{span}\mathbf 1$ on the open simplex. Script s06 (a) confirms kernel dimensions $6,3,0=K(K-\operatorname{rank}CW)$ for $m=2,3,4$ symbols at $K=3$. A logit code with $m$ symbols therefore behaves like a location code of rank at most $m-1$, and parts (i)-(iii) and the modality corollary transfer with $\bar T$ replaced by $CW$. Difficulty: low, one proposition. The general discrete channel $\mathbb P(h\mid\bar y)=\kappa(\bar T\bar\theta^{-1}\bar y)$ with $\kappa$ injective modulo a known group of reparameterizations follows the same pattern, with the stabilizer replaced by the subgroup preserving $\kappa\circ\bar T$.

The compact-group count of D22-COMM-03 should be stated next to part (iii), with the consequence for the program spelled out: if the frame group of the gauge program is $SO(3)$, a two-dimensional public code already pins the dictionary. The invisible directions, and with them the unreachable directions and the filling and detection split of the learning section, then shrink accordingly. Recomputing `it1:sheaf-count` with $\mathfrak g=\mathfrak{so}(K)$ replaces column-wise counting by the dimension of $\{(a_v)\in\mathfrak{so}(K)^{\mathcal V}:\bar T_e(a_i-a_j)=0\}$ modulo constants. That is a moderate calculation, because the column-by-column argument at 17:415 no longer applies to skew matrices.

The remark `it1:exponential` can be replaced by an exact characterization. Near the identity, the set $\{e^{OT}:O\in\R^{K\times r},T\in\R^{r\times K}\}$ equals $\{\theta:\operatorname{rank}(\theta-I)\leq r\}$, because the principal logarithm of $I+N$ is a power series in $N$ and has range inside $\operatorname{range}N$. Script s06 (b) gives $\sigma_{r+1}/\sigma_1\leq7\times10^{-15}$ for $\log(I+N)$ with $\operatorname{rank}N=2$. Code-shaped links are thus the near-identity group elements that move at most an $r$-dimensional subspace and act as the identity on $\ker T$. Stabilizer elements are the opposite: their displacement $g-I$ takes values in $\ker\bar T$. This gives the precise content that the sentence “related only through the Lie algebra” reaches for.

The meaning loss of D22-COMM-07 can be made receiver-evaluable. Replace $\KL(q\Vert\hat q)$ by its posterior expectation over the stabilizer coset, $\E_{s\sim\mathfrak q}[\KL((\bar\theta s)_\#\bar q_j\Vert\hat q)]$, where $\mathfrak q$ is the dictionary recognition law. Under the learning theorem of the same chapter, $\mathfrak q$ converges to the prior conditioned on the coset, so this expected loss has a closed form in the Gaussian tangent model. It connects reception to the learning section without leaving the declared model. Difficulty: moderate.

The bandwidth remark has an exact next-order statement. If $\E_\nu(\log\nu_j-\log\nu_k)^2<\infty$, then $n^{-1}\log$ of the posterior odds equals $\Delta+n^{-1/2}\sigma Z_n+o_p(n^{-1/2})$, with $\Delta=\E_\nu[\log\nu_j-\log\nu_k]$, $\sigma^2=\operatorname{Var}_\nu(\log\nu_j-\log\nu_k)$ and $Z_n\Rightarrow\mathcal N(0,1)$. At fixed $n$ the posterior is therefore a Gibbs row at temperature $1/n$ whose costs fluctuate by order $n^{-1/2}$, which exceeds the temperature. The KL-cost row $\pi_je^{-n\KL(\nu\Vert\nu_j)}/Z$ matches the posterior only in exponential rate, and its prior weights are invisible at that scale. Stating this, with a Berry–Esseen remainder, would keep the temperature-$1/n$ reading from being taken as a finite-$n$ approximation. Difficulty: low.

Two small improvements. `it1:kalman` does not need full row rank: the posterior, precision and mutual-information formulas hold for every $A$ when $R\succ0$ (s01 d). In `it1:location` the positive-definiteness of $J_f$ is automatic for a $C^1$ density with finite Fisher information: if $a^TJ_fa=0$ then $\partial_af=0$ everywhere, and $f$ cannot be integrable.
